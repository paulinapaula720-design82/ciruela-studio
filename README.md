# Ciruela Studio — starter website

A one-page bilingual (Spanish/English) website for GitHub Pages.

## Publish on GitHub Pages
1. Create a GitHub repository named `ciruela-studio` (or another name you prefer).
2. Upload `index.html` to the repository's root folder.
3. Before publishing, open `index.html` and replace `HELLO_EMAIL@example.com` with the real email address you want clients to use.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Before going public
- Replace the sample contact email.
- Review the services and remove anything you do not want to offer yet.
- The portfolio visuals are sample illustrations, not real client work; the page says so.
- Confirm the legal/business details and privacy requirements applicable to your situation before collecting personal data or accepting orders.
- No contact form backend is included; the contact button opens the visitor's email app.
