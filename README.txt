CIRUELA STUDIO — instrukcja publikacji
1. Rozpakuj ZIP.
2. W repozytorium GitHub paul.../ciruela-studio prześlij pliki index.html, styles.css, script.js, ciruela-design.png do katalogu głównego (Add file > Upload files).
3. Zatwierdź Commit changes.
4. Otwórz https://paulinapaula720-design82.github.io/ciruela-studio/ i odśwież Ctrl+F5.
Ważne: widok desktop jest oparty na zatwierdzonej grafice i zawiera napisy jako część obrazu. Na desktopie przełącznik EN zmienia tekst poniższych sekcji i wiadomość WhatsApp, ale napisy na grafice pozostają po hiszpańsku. Na telefonie nagłówek jest prawdziwym tekstem i zmienia język.
Portfolio to sekcja zapowiadająca realizacje, nie fikcyjne przykłady.
